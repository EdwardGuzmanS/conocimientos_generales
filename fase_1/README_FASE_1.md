## Fase 1 – Conocimiento general y entorno

El objetivo es tener una base común de conceptos. Si no conoce alguno de los temas, lo investiga CPU, GPU, Jetson, CUDA y CuPy, SDK, Git.

### Tareas:

1. Clonar el repositorio.
2. Instalar requirements.txt en entorno virtual.(utilizar el que más acomode venv, pipenv, conda entre otros)
3. Crear una rama nueva llamada feature/gpu-available, escribir un script que imprima la GPU detectada por CuPy.
4. Una vez que tenga acceso al repositorio, hacer push de la rama a GitHub.
