## Fase 2 – Cámara y primer TIFF

Conectarse a una cámara Thorlabs o Basler con un script propio, en una rama nueva llamada feature/first-connection.

1. Crear nueva rama feature/first-connection
2. Instalar librería para leer Tiffs.
3. Inicializar el SDK y abrir una cámara.
4. Configurar exposición y ROI, capturar un frame y guardarlo como TIFF de 16 bits.
5. Reabrir el TIFF y verificar que tiene 16 bits y el tamaño del ROI.
